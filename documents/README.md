# 📂 คลังเอกสาร — New Radix Nova Project

## 📁 โครงสร้างโฟลเดอร์

| โฟลเดอร์ | รายการ |
|----------|--------|
| `receipts/` | ใบเสร็จ, ใบแจ้งหนี้, หลักฐานการจ่าย |
| `reports/` | รายงานประจำเดือน, รายงานโครงการ |
| `notes/` | บันทึกย่อ, เอกสารอ้างอิง, บันทึกประชุม |
| `images/` | รูปภาพประกอบ, ภาพหน้าจอ |
| `archives/` | เอกสารเก่า — ย้ายมาเก็บเมื่อไม่ได้ใช้งานแล้ว |

## ✅ กฎการตั้งชื่อไฟล์
รูปแบบแนะนำ: `YYYY-MM-DD-รายละเอียด.นามสกุล`
> ตัวอย่าง: `2026-11-27-ใบเสร็จค่าอินเทอร์เน็ต.pdf`

## ⚠️ ข้อจำกัด
- ไฟล์เดี่ยวไม่เกิน **100MB** (ถ้าเกินจะใช้ Git LFS อัตโนมัติ)
- ตรวจสอบข้อมูลส่วนตัว/ข้อมูลสำคัญก่อนอัพโหลดเสมอ
- ไม่อัพโหลดรหัสผ่าน, เลขบัตรประชาชน หรือข้อมูลลับ

## 📤 วิธีอัพโหลด
1. เข้าโฟลเดอร์ที่ต้องการใน GitHub
2. กด **Add file → Upload files**
3. ลากไฟล์มาวาง หรือเลือกจากเครื่อง
4. เขียนข้อความสั้นๆ ที่ Commit changes เช่น: `เพิ่มใบเสร็จ 27 พ.ย. 69`
5. กด **Commit changes** ✅
