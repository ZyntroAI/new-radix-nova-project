# 📂 เอกสารทั้งหมดในที่นี้

## โครงสร้าง
- **receipts/** — ใบเสร็จ ใบแจ้งหนี้
- **reports/** — รายงานประจำเดือน/โครงการ
- **notes/** — บันทึกย่อ เอกสารอ้างอิง
- **images/** — รูปภาพ
- **archives/** — เอกสารที่ไม่ได้ใช้งานแล้ว

## กฎการอัพโหลด
1. ตั้งชื่อไฟล์ตามรูปแบบ: `YYYY-MM-DD-รายละเอียด.pdf`
2. ไฟล์ต้องไม่เกิน 100MB / ไฟล์
3. ไฟล์ใหญ่กว่า 100MB ใช้ Git LFS
4. ตรวจสอบข้อมูลส่วนตัวก่อนอัพโหลด
