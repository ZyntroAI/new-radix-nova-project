🔁 Sync & Backup Plugins — ปลั๊กอินซิงค์และสำรองข้อมูล
 
รักษาความปลอดภัยให้กับบันทึกของคุณ — ซิงค์ระหว่างอุปกรณ์ + สำรองข้อมูลอัตโนมัติ ✅
 
 
 
📋 สารบัญ
 
- 🔄 ตัวเลือกซิงค์ข้อมูล
- 💾 ตัวเลือกสำรองข้อมูล
- ⚙️ การตั้งค่าแนะนำ
- ✅ Checklist ความปลอดภัย
 
 
 
🔄 ส่วนที่ 1: ตัวเลือกซิงค์ข้อมูลระหว่างอุปกรณ์
 
✅ 1. Obsidian Sync (ทางการ)
 
- ค่าใช้จ่าย: มีค่าบริการรายเดือน/ปี
- จุดเด่น: เข้ารหัสจากต้นทางถึงปลายทาง, ซิงค์แบบเรียลไทม์, ไม่ต้องตั้งค่าอะไรมาก
- เหมาะกับ: ผู้ใช้ที่ต้องการความสะดวกและเชื่อถือได้
- สิ่งที่ซิงค์: บันทึก, รูปภาพ, ปลั๊กอิน, การตั้งค่า, แท็ก, แคนวาส
- ⚠️ ข้อสังเกต: ไม่รวมไฟล์ขนาดใหญ่เกินขีดจำกัด
 
✅ 2. Self-Hosted LiveSync (ฟรี / โฮสต์เอง)
 
- ประเภท: ปลั๊กอินชุมชน
- ต้องการ: CouchDB (โฮสต์เอง หรือใช้บริการภายนอก)
- จุดเด่น: ควบคุมข้อมูลได้เต็มที่, รองรับไฟล์ขนาดใหญ่, ซิงค์แบบเรียลไทม์
- เหมาะกับ: ผู้ใช้ที่ต้องการความเป็นส่วนตัวและมีความรู้ด้านเทคนิค
- ติดตั้ง: ติดตั้งจาก Community Plugins → ค้นหา Self-Hosted LiveSync
 
✅ 3. บริการคลาวด์ทั่วไป
 
บริการ ข้อดี ข้อสังเกต 
Dropbox ใช้ง่าย, มีประวัติไฟล์ ซิงค์ไม่เรียลไทม์เท่า, ระวังไฟล์ขัดแย้ง 
OneDrive มาพร้อม Windows/Office ตั้ค่าให้ตรวจสอบไฟล์น้อยลง 
Google Drive พื้นที่เยอะ, เข้าถึงได้ทุกที่ การตั้งค่าซับซ้อนกว่า 
Syncthing ฟรี, P2P, ไม่มีเซิร์ฟเวอร์กลาง ต้องติดตั้งและตั้งค่าทุกเครื่อง 
 
⚠️ สำคัญ: เมื่อใช้คลาวด์ทั่วไป → ปิดการทำงานอัตโนมัติของปลั๊กอินระหว่างซิงค์ เพื่อป้องกันไฟล์เสียหาย/ขัดแย้ง
 
 
 
💾 ส่วนที่ 2: ปลั๊กอินสำรองข้อมูล
 
🏆 แนะนำอันดับ 1: Obsidian Backup Plugin
 
- ชื่อ: Obsidian Backup (โดย: mnaoumov)
- คุณสมบัติ:
- สำรองอัตโนมัติตามช่วงเวลาที่กำหนด
- บีบอัดเป็น ZIP ประหยัดพื้นที่
- เก็บประวัติตามจำนวนที่กำหนด (ลบเก่าอัตโนมัติ)
- สามารถสำรองไปยังโฟลเดอร์ภายนอก/ไดรฟ์อื่น
- การตั้งค่าแนะนำ:
- ⏱️ ความถี่: ทุก 4 ชม. หรือ ทุกครั้งที่เปิด/ปิด Obsidian
- 📁 จำนวนเก็บไว้: 10–30 ชุด
- 📂 ตำแหน่ง: โฟลเดอร์อื่นนอกจาก Vault หรือไดรฟ์อื่น
 
✅ ตัวเลือกอื่นๆ
 
ปลั๊กอิน คุณสมบัติพิเศษ 
Remotely Save อัปโหลดสำรองไปยัง: OneDrive, Google Drive, Dropbox, S3, WebDAV — ตั้งเวลาอัตโนมัติได้ 
Git Backup บันทึกประวัติทุกการเปลี่ยนแปลงด้วย Git — เหมาะกับผู้ใช้ที่ต้องการควบคุมเวอร์ชัน 
Periodic Notes Backup สำรองเฉพาะบันทึกประจำวัน/สัปดาห์ — เบาและรวดเร็ว 
 
 
 
⚙️ ส่วนที่ 3: การตั้งค่าแนะนำ — ผสมผสานเพื่อความปลอดภัยสูงสุด

📋 สิ่งที่ควรสำรองเสมอ
 
- ✅ ไฟล์บันทึก ( .md ) — สำคัญที่สุด
- ✅ โฟลเดอร์  .obsidian/  — การตั้งค่า, ปลั๊กอิน, แท็ก, แคนวาส
- ✅ สิ่งที่แนบมา: รูปภาพ, PDF, ไฟล์อื่นๆ ใน Vault
- ❌ ไม่จำเป็น: ไฟล์ข้อมูลขนาดใหญ่ที่มีสำเนาอยู่แล้ว
 
 
 
⚠️ ข้อควรระวัง & Best Practices
 
✅ ควรทำ ❌ ไม่ควรทำ 
มีอย่างน้อย 2 ช่องทางสำรอง (เช่น Sync + Remotely Save) พึ่งพาแค่ช่องทางเดียว 
ทดสอบการกู้คืนเป็นประจำทุก 3–6 เดือน ติดตั้งแล้วลืม ไม่เคยตรวจสอบ 
ตั้งรหัสผ่าน/เข้ารหัสไฟล์สำรอง อัปโหลดขึ้นคลาวด์โดยไม่เข้ารหัส 
ยกเว้นไฟล์ขนาดใหญ่ที่ไม่จำเป็นออกจากการซิงค์ ซิงค์ทุกไฟล์โดยไม่กรอง — ช้าและเสียค่าใช้จ่าย 
ปิดซิงค์ก่อนทำการเปลี่ยนแปลงขนาดใหญ่ ลบ/ย้ายโฟลเดอร์ขนาดใหญ่ขณะกำลังซิงค์ 
ตรวจสอบพื้นที่ว่างเป็นประจำ ปล่อยให้พื้นที่เต็มโดยไม่รู้ตัว 
 
 
 
✅ Checklist — ระบบสำรองและซิงค์ทำงานสมบูรณ์ไหม?
 
มีระบบซิงค์ระหว่างอุปกรณ์ที่ทำงานอยู่ ✅
มีระบบสำรองไฟล์ไปยังตำแหน่งอื่นนอกจาก Vault ✅
สำรองอัตโนมัติ — ไม่ต้องคอยทำเองด้วยตนเอง ✅
ตรวจสอบไฟล์สำรองล่าสุดว่ามีอยู่และอ่านได้จริง ✅
รู้วิธีกู้คืนข้อมูลเมื่อเกิดปัญหา ✅
ไฟล์สำคัญทั้งหมดถูกรวมอยู่ในระบบแล้ว ✅
ตั้งค่าการลบไฟล์สำรองเก่าเพื่อประหยัดพื้นที่ ✅
รหัสผ่าน/การเข้ารหัสได้รับการตั้งค่าถูกต้อง ✅
