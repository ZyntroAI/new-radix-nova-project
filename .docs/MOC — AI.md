🗺️ MOC — AI
 
📋 Overview
 
แผนที่ความรู้กลางด้านปัญญาประดิษฐ์ — รวบรวมแนวคิดพื้นฐาน ประเภทของ AI เทคโนโลยี เครื่องมือ และแนวทางการประยุกต์ใช้ ตั้งแต่ระดับเบื้องต้นจนถึงขั้นสูง
 
🧱 Core Areas
 
🤖 Fundamentals
 
ความหมายและประเภทของ AI (Narrow vs AGI)
ประวัติและวิวัฒนาการของ AI
แนวคิดจริยธรรมและความรับผิดชอบในการใช้ AI
 
🧠 Machine Learning
 
พื้นฐาน Machine Learning
การเรียนรู้แบบมีผู้สอน (Supervised Learning)
การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning)
การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning)
 
🧬 Deep Learning & Neural Networks
 
โครงข่ายประสาทเทียมเบื้องต้น
Transformer Architecture
CNN, RNN และสถาปัตยกรรมอื่นๆ
 
💬 Generative AI & LLM
 
Large Language Models (LLM)
Prompt Engineering
RAG (Retrieval-Augmented Generation)
AI Agents & Multi-Agent Systems
การสร้างเนื้อหา รูปภาพ และวิดีโอด้วย AI
 
🛠️ Tools & Frameworks
 
Python (Pandas, NumPy)
PyTorch / TensorFlow
LangChain / LangGraph / CrewAI
OpenAI API / OpenRouter
Vector Databases

🎯 Learning Path
 
🟢 Beginner
 
1. เข้าใจภาพรวม AI คืออะไร และประเภทต่างๆ
2. เรียนรู้พื้นฐาน Python และการจัดการข้อมูล
3. ทดลองใช้งานเครื่องมือ AI ทั่วไปและเขียน Prompt เบื้องต้น
 
🟡 Intermediate
 
1. เข้าใจหลักการทำงานของ Machine Learning และ Deep Learning
2. ฝึกใช้ API และสร้างแอปพลิเคชันที่ผสาน AI
3. เรียนรู้การเตรียมข้อมูลและสร้างระบบ RAG
 
🔴 Advanced
 
1. ปรับแต่งและฝึกฝนโมเดล (Fine-tuning)
2. ออกแบบสถาปัตยกรรมระบบ AI และ AI Agents
3. ประเมินความปลอดภัย ความเป็นส่วนตัว และต้นทุน
