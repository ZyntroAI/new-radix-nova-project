ลิงก์ขาออกสำคัญเกี่ยวกับ Obsidian Developer Docs สำหรับการพัฒนา Plugin, Theme หรือเชื่อมต่อระบบภายนอกผ่าน API:
1. เอกสารทางการ (Official Developer Docs)
 * เว็บไซต์หลัก Obsidian Developer Docs:
   https://docs.obsidian.md/Home
   (ศูนย์รวมคำแนะนำการสร้าง Plugin, Theme และ Reference ของ TypeScript API)
 * API References (TypeScript API):
   https://docs.obsidian.md/Reference/TypeScript+API/App
   (เอกสารจัดการ App, Vault, MetadataCache, Workspace, FileManager)
 *8 Vault Operations Guide:
   https://docs.obsidian.md/Plugins/Vault
   (คู่มือการอ่าน/เขียน และประมวลผลไฟล์ Markdown แบบ Safe read-modify-write)
2. GitHub Repositories & Starter Kits
 * GitHub Repository ของ Developer Docs:
   https://github.com/obsidianmd/obsidian-developer-docs
   (ซอร์สโค้ดของเว็บไซต์เอกสารพัฒนา Obsidian ที่สามารถทำการ Fork หรือส่ง PR ช่วยปรับปรุงได้)
 * Official Sample Plugin Starter:
   https://github.com/obsidianmd/obsidian-sample-plugin
   (แม่แบบเริ่มต้นสำหรับการพัฒนา Community Plugin ด้วย TypeScript และ esbuild)
3. ชุมชนนักพัฒนา & การสนับสนุน (Community & Support)
 * Obsidian Help (Developers Overview):
   https://obsidian.md/help/developers
   (หน้าภาพรวมแนวทางการมีส่วนร่วม Open Source เช่น JSON Canvas, Web Clipper, Importer)
 * Official Discord Server:
   ช่อง plugin-dev และ theme-dev บน Discord อย่างเป็นทางการของ Obsidian
 * Obsidian Forum (Developers & API):
   https://forum.obsidian.md/
   (หมวดหมู่ Developers & API และ Share & Showcase สำหรับแลกเปลี่ยนเทคนิคการพัฒนา)
