📁 Filesystem — ระบบไฟล์มาตรฐาน
 
โครงสร้างโฟลเดอร์และกฎการตั้งชื่อไฟล์ เพื่อให้ทุกคนเข้าใจและทำงานร่วมกันได้อย่างเป็นระเบียบ ✅
 
 
 
📂 โครงสร้างโฟลเดอร์มาตรฐาน

🔄 กฎการทำงานกับระบบไฟล์
 
✅ การย้ายและเปลี่ยนชื่อ
 
- ใช้แผงไฟล์ใน Obsidian เสมอ ไม่ใช้ File Explorer ภายนอก — เพื่อให้ลิงก์และ Backlinks อัปเดตอัตโนมัติ
- ตรวจสอบก่อนย้าย: คลิกไฟล์ → แท็บ Backlinks — ดูว่ามีใครอ้างถึงอยู่ไหม
- ถ้าต้องเปลี่ยนชื่อที่สำคัญ → เพิ่มชื่อเดิมลงใน  aliases:  ใน Frontmatter เพื่อไม่ให้ลิงก์เก่าพัง
 
✅ การลบไฟล์
 
- ย้ายไปที่โฟลเดอร์  Sources/Archives/  ก่อน ลบทิ้งทันทีเฉพาะที่แน่ใจ
- ตรวจสอบ Backlinks ก่อนลบเสมอ — ถ้ามีคนอ้างถึง ให้อัปเดตลิงก์ก่อนหรือย้ายไปเก็บถาวรพร้อมโน้ตบอกที่อยู่ใหม่
 
✅ ขนาดและจำนวนไฟล์
 
- แยกไฟล์ไม่ให้ใหญ่เกิน 200–300 บรรทัด — แบ่งเป็นหัวข้อย่อย
- แยกโฟลเดอร์เมื่อมีไฟล์เกิน 20–30 ไฟล์ — สร้าง MOC เพื่อเชื่อมโยง
- เก็บรูปภาพและไฟล์ขนาดใหญ่ใน  Assets/  ไม่ผสมกับไฟล์  .md 
 
 
 
⚠️ ข้อควรระวังเมื่อใช้ร่วมกับบริการซิงค์
 
✅ ควรทำ ❌ ไม่ควรทำ 
ปิดซิงค์ก่อนย้าย/ลบโฟลเดอร์จำนวนมาก ย้ายไฟล์ขณะกำลังซิงค์ทำงาน — อาจเกิด Conflict 
ซิงค์เฉพาะโฟลเดอร์หลัก ไม่ซิงค์ไฟล์ชั่วคราว ซิงค์ทุกอย่างรวมถึงไฟล์ขยะ — ช้าและเสียพื้นที่ 
ตรวจสอบพื้นที่ว่างเป็นประจำ ปล่อยให้พื้นที่เต็มโดยไม่รู้ตัว 
หลีกเลี่ยงชื่อไฟล์เหมือนกัน ต่างแค่ตัวพิมพ์เล็ก-ใหญ่  Note.md  กับ  note.md  — ปัญหาบนระบบบางแพลตฟอร์ม
