🗺️ MOC — Software Engineering
 
📋 Overview
 
แผนที่ความรู้รวบรวมแนวคิด กระบวนการ และหลักการสำคัญด้านวิศวกรรมซอฟต์แวร์ — จุดอ้างอิงหลักสำหรับทุกหัวข้อที่เกี่ยวข้องกับการพัฒนาและจัดการซอฟต์แวร์อย่างเป็นระบบ
 
🌱 Core Concepts — Development Methodologies
 
แบบจำลองกระบวนการพัฒนา
 
- [[Waterfall Model]] — แบบจำลองน้ำตก: ทำงานทีละขั้น ตามลำดับเส้นตรง
- [[Agile Development]] — แบบอไจล์: วนซ้ำ รอบสั้น ปรับเปลี่ยนได้ตลอดเวลา

🎯 Learning Path
 
🟢 Beginner
 
1. เข้าใจภาพรวม: วิศวกรรมซอฟต์แวร์คืออะไร
2. เปรียบเทียบ [[Waterfall Model]] กับ [[Agile Development]]
3. เรียนรู้ขั้นตอนพื้นฐานของ SDLC
 
🟡 Intermediate
 
1. เลือกกระบวนการที่เหมาะกับประเภทโครงการ
2. เจาะลึก Scrum, Kanban และวิธีการอื่นๆ
3. เรียนรู้การจัดการความต้องการและการออกแบบ
 
🔴 Advanced
 
1. สถาปัตยกรรมซอฟต์แวร์
2. การประกันคุณภาพและการทดสอบ
3. DevOps, ความปลอดภัย และการปฏิบัติงานแบบมืออาชีพ
