# Hub Node ที่แนะนำ

สร้างโน้ตกลางเพิ่มเติม

```markdown
# Kubernetes Domain

## Infrastructure

- [[Kubernetes Cluster]]

## Components

- [[API Gateway Component]]

## Errors

- [[ERR-K8S-001]]

## Incidents

- [[INC-2026-001]]

## Runbooks

- [[PodCrashLoopBackOff]]
```

จะทำให้ Graph แยกเป็น Domain ได้ชัดเจน เช่น

```text
Kubernetes Domain
├─ Cluster
├─ Components
├─ Errors
├─ Incidents
├─ RCA
├─ Runbooks
└─ Monitoring
```

เหมาะสำหรับ Obsidian Vault สาย SRE / DevOps / Platform Engineering ที่ต้องการ trace ปัญหาได้ตั้งแต่ Service → Component → Error → Incident → RCA → Runbook → Monitoring → SLO ในคลิกเดียว.
