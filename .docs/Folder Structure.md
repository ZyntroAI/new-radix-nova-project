📂 Folder Structure — โครงสร้างโฟลเดอร์มาตรฐาน
 
จัดระเบียบ Vault ให้หาง่าย สะอ้อมตา และซิงค์ได้ราบรื่น ✅
 
 
 
🗺️ ภาพรวมโครงสร้าง
 
plaintext
  
your-vault/
├── 🧠 Atlas/              # ความรู้ถาวร — สาระสำคัญ
│   ├── Concepts/          # แนวคิด หลักการ ทฤษฎี
│   ├── MOCs/              # แผนผังเนื้อหา
│   └── Resources/         # แหล่งอ้างอิง
├── 🚧 Projects/           # โครงการที่กำลังดำเนิน
│   ├── Project Hub.md     # ← จุดรวมทุกโครงการ
│   ├── Project-A/
│   └── Project-B/
├── 🏠 Areas/              # ขอบเขตความรับผิดชอบ
│   ├── Work/
│   ├── Personal/
│   └── Learning/
├── 📥 Sources/            # วัตถุดิบ — บันทึกดิบ
│   ├── Inbox.md
│   ├── Notes/
│   └── Archives/
├── 📋 Templates/          # แม่แบบบันทึก
├── 🖼️ Assets/             # ไฟล์แนบ รูปภาพ เอกสาร
│   ├── Images/
│   ├── Documents/
│   └── Attachments/
└── ⚙️ .obsidian/         # การตั้งค่า — อย่าแตะ
 
 
 
 
📖 คำอธิบายแต่ละโฟลเดอร์
 
โฟลเดอร์ วัตถุประสงค์ ประเภทไฟล์ที่อยู่ข้างใน 
Atlas/ ความรู้ที่จัดระเบียบแล้ว — คุณค่าหลักของ Vault บันทึกถาวร, MOC, แนวคิด, อ้างอิง 
Projects/ งานเฉพาะกิจ มีวันเริ่มและจบ บันทึกโครงการ, งานมอบหมาย, ความคืบหน้า 
Areas/ ด้านที่คุณดูแลอย่างต่อเนื่อง งานประจำ, ทักษะ, ชีวิตส่วนตัว 
Sources/ ข้อมูลดิบ ยังไม่ได้จัดระเบียบ บันทึกย่อ, ข่าว, บทความที่เก็บไว้อ่าน 
Templates/ แม่แบบ Frontmatter และโครงร่าง ไฟล์ .md ที่ใช้สร้างบันทึกใหม่ 
Assets/ สิ่งที่ไม่ใช่ข้อความ รูปภาพ, PDF, ไฟล์ข้อมูล, สื่ออื่นๆ 
 
 
 
🔗 ลิงก์ย่อยที่เกี่ยวข้อง
 
- [[Filesystem]] — กฎการตั้งชื่อไฟล์, การย้าย-ลบไฟล์
- [[Project Hub]] — จุดรวมและภาพรวมทุกโครงการ
- [[Sync & Backup Plugins]] — วิธีซิงค์และสำรองแต่ละโฟลเดอร์
- [[Tag System]] — ระบบป้ายเสริมโครงสร้าง
- [[MOC — YAML Auto-Fixer]] — เครื่องมือรักษามาตรฐาน Frontmatter
 
 
 
💡 หลักการสำคัญ
 
- ใช้โฟลเดอร์แยกประเภทงาน ไม่ใช่แยกเวลา — ค้นหาได้โดยไม่ต้องจำวันที่เขียน
- ไม่ต้องซ้อนลึกเกินไป — สูงสุด 2–3 ชั้นก็พอ ลิงก์จะช่วยเชื่อมข้ามโฟลเดอร์เอง
- MOC เชื่อมทุกอย่างเข้าด้วยกัน — โครงสร้างไม่ใช่กำแพง ลิงก์ข้ามโฟลเดอร์ได้อย่างอิสระ
- ปรับแต่งได้ตามความเหมาะสม — นี่คือมาตรฐานแนะนำ ปรับให้เข้ากับสไตล์การทำงานของคุณได้เลย ✅
 
 
 
✅ Checklist โครงสร้างสมบูรณ์
 
มีโฟลเดอร์หลักครบ 6 โฟลเดอร์ ✅
มี  Project Hub.md  ในโฟลเดอร์ Projects ✅
ไฟล์แนบทั้งหมดอยู่ใน  Assets/  ✅
มี  Inbox.md  สำหรับบันทึกดิบ ✅
มีโฟลเดอร์  Archives/  สำหรับเก็บของเก่า ✅
ทุกหน้า MOC มีลิงก์กลับมาที่หน้านี้ ✅
ไม่มีไฟล์  .md  วางอยู่รากโฟลเดอร์โดยไม่จำเป็น ✅
