🚚 คู่มือการย้ายโน้ตจากระบบอื่นมา Obsidian
 
💡 หลักการสำคัญ: Obsidian อ่านไฟล์ Markdown ปกติได้เลย — ไม่มีรูปแบบลับ ดังนั้นการย้ายจึงง่ายกว่าระบบอื่นมาก
 
 
 
📋 ขั้นตอนทั่วไป (ใช้ได้กับทุกระบบ)
 
1. สำรองข้อมูลจากระบบเดิม — ส่งออกเป็น Markdown/Text/HTML
2. จัดระเบียบไฟล์ — แยกหมวดหมู่ในโฟลเดอร์ชั่วคราวก่อนย้าย
3. แก้ไขลิงก์และรูปภาพ — ปรับให้เป็นรูปแบบ  [[ชื่อโน้ต]]  หรือ  ![[รูป.jpg]] 
4. ย้ายเข้าโฟลเดอร์ Vault — ก๊อปปี้ไฟล์ลงในโฟลเดอร์ที่เหมาะสม
5. เปิด Obsidian → สนุกกับระบบใหม่! ✅
 
 
 
🔄 คู่มือแยกตามระบบที่ใช้อยู่
 
 
 
📝 1. จาก Notion
 
✅ วิธีส่งออกจาก Notion
 
1. เปิดหน้าที่ต้องการย้าย →  ···  → Export
2. เลือก Markdown & CSV
3. ✅ Include: Everything → ❌ ไม่ต้องการ Include files
4. ดาวน์โหลดไฟล์ ZIP แตกไฟล์ออกมา
 
⚠️ สิ่งที่ต้องแก้ไข
 
- ลิงก์ภายในจะเป็น  [ชื่อ](ชื่อ%20หน้า.md)  → เปลี่ยนเป็น  [[ชื่อ หน้า]] 
- รูปภาพและไฟล์แนบจะอยู่ในโฟลเดอร์ย่อย — ย้ายไปรวมที่  06-Attachments/  แล้วแก้ลิงก์
- หัวข้อหน้าอาจซ้ำกัน — เช็คและเปลี่ยนชื่อให้ไม่ซ้ำกัน
 
🤖 เครื่องมือช่วย
 
- ปลั๊กอิน: Notion Importer (ในชุมชนปลั๊กอิน Obsidian)
- หรือใช้เครื่องมือออนไลน์:  notion2md 
 
 
 
📓 2. จาก Evernote
 
✅ วิธีส่งออกจาก Evernote
 
1. เลือกโน้ต/สมุดบันทึก → ขวาคลิก → Export Note
2. เลือกรูปแบบ: ENEX
3. ใช้เครื่องมือแปลง:
- ปลั๊กอิน Obsidian: Evernote Importer
- หรือเครื่องมือ:  evernote2md  (แนะนำ — ใช้ง่ายและสะอาดที่สุด)
 
bash
  
# ติดตั้ง evernote2md แล้วแปลง
evernote2md your-notes.enex ./output-folder
 
 
⚠️ สิ่งที่ต้องระวัง
 
- แท็กใน Evernote จะกลายเป็น  tags: [...]  ใน Properties โดยอัตโนมัติ ✅
- รูปภาพจะถูกแปลงและแยกเป็นไฟล์แนบ
- ตรวจสอบการจัดรูปแบบข้อความบางส่วนอาจผิดเพี้ยนเล็กน้อย
 
 
 
📘 3. จาก OneNote
 
✅ วิธีส่งออก
 
- ทางเลือก 1: ส่งออกเป็น PDF → คัดลอกข้อความ — แนะนำให้น้อยที่สุด 😅
- ทางเลือก 2: ใช้เครื่องมือ:  OneNote to Markdown 
- ทางเลือก 3: ปลั๊กอินชุมชน: OneNote Importer
 
⚠️ OneNote มีรูปแบบที่ซับซ้อน — บางครั้งต้องปรับแก้ด้วยมือบ้างเล็กน้อย
 
 
 
🖊️ 4. จาก Google Keep
 
✅ วิธีส่งออก
 
- ใช้ Google Takeout: takeout.google.com
- เลือกเฉพาะ Keep → ส่งออกเป็น HTML หรือ JSON
- ใช้สคริปต์/เครื่องมือแปลง:  keep-exporter  → แปลงเป็นไฟล์ Markdown แยกไฟล์
 
⚠️ สิ่งที่ต้องระวัง
 
- ไม่มีลิงก์ภายใน — ต้องสร้างความเชื่อมโยงใหม่เอง
- ป้ายกำกับจะกลายเป็นแท็ก
- เวลาสร้าง/แก้ไขจะอยู่ในเนื้อหา — ย้ายไปใส่ Properties ด้วยมือหรือสคริปต์
 
 
 
📖 5. จาก Apple Notes
 
✅ วิธีส่งออก
 
- ใช้แอปบน Mac: ปลั๊กอิน Notes to Markdown หรือสคริปต์  apple-notes-to-markdown 
- หรือใช้แอป Yank Note เปิดและส่งออกเป็น Markdown
 
⚠️ ต้องทำบนเครื่อง Mac เท่านั้น
 
 
 
📄 6. จากไฟล์ข้อความทั่วไป (.txt, .md, .rtf)
 
✅ ง่ายที่สุด! แค่ก๊อปปี้ไฟล์ลงโฟลเดอร์ Vault ได้เลย
 
- เปลี่ยนชื่อจาก  .txt  เป็น  .md 
- เพิ่มหัวข้อ  # ชื่อเรื่อง  ที่บรรทัดแรกถ้าต้องการ
- เพิ่ม Properties ที่ส่วนบนตามรูปแบบที่ต้องการ
 
 
 
📋 7. จาก Joplin
 
✅ วิธีส่งออก
 
1. Joplin → ไฟล์ → ส่งออกทั้งหมด → Markdown
2. แตกไฟล์ → ก๊อปปี้ทั้งหมดลงในโฟลเดอร์ Vault ของคุณ
 
💡 Joplin ใช้ Markdown เหมือนกันเกือบทั้งหมด — ย้ายแล้วใช้งานได้เลย เกือบไม่ต้องแก้ไขอะไร ✅
 
 
 
🔧 ขั้นตอนหลังย้าย — สำคัญมาก!
 
1️⃣ ปรับชื่อไฟล์ให้สอดคล้องกัน
 
- ✅ ใช้ชื่อที่อ่านง่าย ไม่มีอักขระพิเศษ:  API Design.md 
- ❌ หลีกเลี่ยงชื่อยาวเกินไป หรือใช้วันที่นำหน้าไม่จำเป็น
- ✅ ตรวจสอบว่าไม่มีชื่อซ้ำกัน
 
2️⃣ ปรับลิงก์ภายในให้เป็นรูปแบบ Obsidian
 
plaintext
  
เดิม: [ชื่อหน้า](ชื่อหน้า.md)
ใหม่: [[ชื่อหน้า]]

เดิม: ![รูปภาพ](images/photo.jpg)
ใหม่: ![[photo.jpg]]
 
 
💡 ใช้ปลั๊กอิน Find and Replace in Files เพื่อแก้ไขทีละหลายไฟล์ได้
 
3️⃣ ย้ายไฟล์แนบและรูปภาพ
 
- รวบรวมรูปภาพ/ไฟล์ทั้งหมดไว้ที่โฟลเดอร์เดียว:  06-Attachments/Images/ 
- อัปเดตลิงก์ในเนื้อหาให้ชี้ไปที่ตำแหน่งใหม่
 
4️⃣ เพิ่ม Properties มาตรฐาน
 
เลือกไฟล์สำคัญ → เพิ่ม Properties เบื้องต้น:
 
yaml
  
---
aliases: ["ชื่อเดิม", "ชื่ออื่น"]
tags: []
created: 2026-10-27
source: Notion / Evernote / เดิม
---
 
 
5️⃣ จัดเข้าโครงสร้างโฟลเดอร์
 
ย้ายไฟล์เข้าหมวดหมู่ตามที่วางแผนไว้ใน [[Obsidian Vault Setup Guide]]
 
 
 
⚡ เคล็ดลับสำหรับการย้ายจำนวนมาก
 
🤖 สคริปต์เบื้องต้นสำหรับเปลี่ยนลิงก์
 
บันทึกเป็นไฟล์  convert-links.py  แล้วรันในโฟลเดอร์โน้ต:
 
python
  
import os
import re

for root, dirs, files in os.walk("."):
    for filename in files:
        if filename.endswith(".md"):
            path = os.path.join(root, filename)
            with open(path, "r", encoding="utf-8") as f:
                content = f.read()
            
            # เปลี่ยน [ชื่อ](ชื่อ.md) เป็น [[ชื่อ]]
            content = re.sub(r'\[([^\]]+)\]\([^/]+\.md\)', r'[[\1]]', content)
            
            with open(path, "w", encoding="utf-8") as f:
                f.write(content)
print("✅ แปลงลิงก์เสร็จสิ้น!")
 
 
⚠️ สำรองไฟล์ก่อนรันสคริปต์ทุกครั้ง!
 
📊 แผนการย้ายแบบค่อยเป็นค่อยไป
 
ระยะเวลา ทำอะไร 
สัปดาห์ที่ 1 ย้ายโน้ตที่ใช้บ่อยที่สุดก่อน → เริ่มใช้ Obsidian สำหรับเรื่องใหม่ 
สัปดาห์ที่ 2–3 ย้ายโน้ตเก่าๆ ที่สำคัญ → ทยอยปรับปรุงเนื้อหาไปในตัว 
เดือนที่ 1–2 ย้ายส่วนที่เหลือทีละหมวดหมู่ → ปิดระบบเดิมเมื่อพร้อม 
 
💡 ไม่ต้องรีบย้ายทั้งหมดในวันเดียว! ย้ายเฉพาะที่จำเป็น แล้วค่อยทยอยย้ายทีละส่วน จะได้ไม่เครียดและมีโอกาสปรับปรุงเนื้อหาไปในตัว ✅
 
 
 
⚠️ ปัญหาที่พบบ่อย & วิธีแก้
 
ปัญหา สาเหตุ วิธีแก้ 
ลิงก์หัก/ไม่ทำงาน ชื่อไฟล์ไม่ตรงกับชื่อในลิงก์ เปลี่ยนชื่อไฟล์ให้ตรงกัน หรือใช้ `[[ชื่อไฟล์ 
รูปภาพไม่แสดง path รูปผิด ย้ายรูปมาโฟลเดอร์เดียวกัน แล้วใช้  ![[ชื่อรูป.jpg]]  
อักขระแปลกๆ การเข้ารหัสไฟล์ไม่ตรงกัน เปิดไฟล์ด้วยโปรแกรมแก้ไข → บันทึกใหม่ด้วย UTF-8 
ชื่อไฟล์ซ้ำกัน ระบบเดิมอนุญาตให้มีชื่อเหมือนกัน เปลี่ยนชื่อให้ไม่ซ้ำ เช่น  API Design.md  และ  API Design — Notes.md  
ไฟล์ใหญ่เกินไป มีรูป/ไฟล์แนบจำนวนมาก ย้ายไฟล์ขนาดใหญ่ออกนอก Vault หรือใช้ลิงก์ภายนอกแทน
