## 📢 Reporting a Vulnerability — PLEASE DO NOT OPEN PUBLIC ISSUES
**Do NOT report security bugs via public GitHub Issues / Discussions / Social Media.**

### ✅ How to Report (Secure)
- 📧 **Email:** `security@zyntroai.com` (PGP Encrypted Preferred)
- 🔐 **GitHub Private Report:** https://github.com/ZyntroAI/new-crystalcastle/security/advisories/new
- 📝 **Template Required:** See below

### ⏱️ Response Timeline
- **Acknowledge:** Within **48 hours**
- **Triaging:** Within **3–5 days**
- **Fix & Disclosure:** Within **90 days** (critical: 14 days)
- **Status Updates:** Every **14 days**
