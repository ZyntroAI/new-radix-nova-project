# ✨ New Radix Nova Project — README (Final Production Version)

---

## 🚀 Overview
**New Radix Nova Project** — Next-generation intelligent application foundation. Built for **AI-assisted development**, **event-driven project tracking**, and **DevSecOps from day one**. Evolves seamlessly from prototype → MVP → enterprise.

> **Core Philosophy:** *No guessing — every status, metric, and decision comes from verifiable sources of truth.*

---

## ✨ Key Features

### 🧠 Intelligence Layer
- **Project Status Auto-Update** — Event-driven state machine; calculates progress/health **from Git/PR/CI/Tasks**, never guesses
- **Code-Document Orchestrator** — Auto-detect TSX/JSX/JS/SH/DOCX; separate executable logic from document artifacts
- **Immutable History** — Every state change logged with evidence; never lose context

### 🛡️ DevSecOps Built-In
- **CI/CD Ready** — GitHub Actions workflows, PR templates, auto-labeling
- **Security Gates** — Shell hardening, dependency scanning, approval gates
- **Least-Privilege** — Skill permissions scoped; broad access never granted

### 🧩 Developer Experience
- **Modern Stack** — React + TypeScript frontend; FastAPI/NestJS backend
- **Unified Workflow** — `commit → branch → PR → review → CI → deploy` tracked end-to-end
- **CrystalCastle Native** — Fully compatible with existing skills, standards, and ecosystem

## 🚀 Quick Start
```bash
# 1. Clone
git clone https://github.com/ZyntroAI/new-radix-nova-project.git
cd new-radix-nova-project

# 2. Environment
cp .env.example .env
# Edit .env with your values

# 3. Install & Setup
npm install
pip install -r requirements.txt

# 4. Develop
npm run dev
# or
uvicorn src.main:app --reload

# 5. Check Project Status (auto-computed)
python -m skills.project_status
```
