Python Library

ไทย: Python Library คือชุดโค้ดที่ติดตั้งแล้วนำมา import ใช้งานในโปรเจกต์ได้

English: A Python library is reusable code distributed as a package that an application can install and import.

Recommended Architecture

สำหรับ architecture ที่ใช้ FastAPI + AI Agent + Schema + CI/CD สามารถจัดโครงสร้าง package ได้ดังนี้ 

pure-agent-dev/
├── pyproject.toml
├── requirements.txt
├── src/
│   └── agent/
│       ├── api/
│       ├── schemas/
│       ├── agents/
│       ├── planners/
│       ├── providers/
│       └── services/
└── tests/

Architecture Components

Component Responsibility
api/ FastAPI routes and HTTP endpoints
schemas/ Pydantic models and JSON Schema definitions
agents/ AI agent implementations
planners/ Task planning and execution strategies
providers/ External AI, cloud and infrastructure providers
services/ Business logic and application services
tests/ Unit, integration and API tests

Installation

python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt

Development Commands

# Run API
uvicorn agent.main:app --reload

# Run tests
pytest

# Lint
ruff check .

# Format
ruff format .

# Type checking
mypy src/

Python Package Installation

หากโปรเจกต์ใช้ pyproject.toml สามารถติดตั้ง package ใน editable mode ได้ 

pip install -e .
Design principle: แยก API, Schema, Agent, Planner, Provider และ Service ออกจากกัน เพื่อไม่ให้ business logic, AI provider และ HTTP layer กลายเป็นก้อนเดียวที่แก้ทีหนึ่งแล้วพังอีกสามสิบจุด

English: This structure keeps HTTP handling, schemas, agent logic, planning, providers and business services independently testable and replaceable.
